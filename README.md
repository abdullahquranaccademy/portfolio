# ABDULLAH portfolio
Run: `python3 -m http.server 8000` in this folder (or VS Code Live Server) → http://localhost:8000
Edit contact details, social URLs, CV path and project links in ONE place: `js/script.js` → `CONFIG`.
Fonts (Syne + Outfit) load from Google Fonts; to match your design's font exactly, change `--font-display` / `--font-body` in `css/style.css`.
Images in assets/images were cropped from your screenshots – replace with originals using the same file names.
